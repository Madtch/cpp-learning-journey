## 🚀 Getting Started

### Prerequisites

Make sure you have Git and a C++ compiler that supports the **C++17 standard** installed on your system.

### 🐧 Linux (Ubuntu / Debian)

Install GCC and essential build tools:

```bash
sudo apt update
sudo apt install build-essential g++
```

### 🪟 Windows

Choose one of the following development environments:

**Option 1 — WSL 2 (Recommended)**

Install WSL with Ubuntu:

```powershell
wsl --install -d Ubuntu
```

Then, open your Ubuntu terminal and install GCC:

```bash
sudo apt update
sudo apt install build-essential g++
```

**Option 2 — MinGW-w64 / MSYS2**

Install GCC through [MSYS2](https://www.msys2.org/) and configure the compiler in your system PATH.

### 🍎 macOS

Install Apple's Command Line Tools, which include Clang:

```bash
xcode-select --install
```

### 📥 Clone the Repository

Clone this repository using Git:

```bash
git clone https://github.com/Madtch/cpp-learning-journey.git

cd cpp-learning-journey
```

---

## ⚙️ Compile & Run

### Compile a C++ Source File

Navigate to the repository directory and compile the desired source file using `g++`:

```bash
g++ -std=c++17 data-structure/switch-case.cpp -o app
```

### Run the Executable

**Linux / macOS / WSL**

```bash
./app
```

**Windows (Command Prompt)**

```cmd
app.exe
```

**Windows (PowerShell)**

```powershell
.\app.exe
```

> **Note:** Replace `data-structure/switch-case.cpp` with the path to your desired C++ source file. The executable name and extension may vary depending on your operating system.
